# Руководство владельца проекта

## Для чего платформа
Городская доска объявлений и сервис взаимопомощи жителей Амурска: «Отдам даром», «Подработка», «Продам», «Потеряно», «Найдено», «Транспорт/такси», «Услуги», профили, личные сообщения, история города и воспоминания жителей.

## Как запустить демонстрационный сайт
1. Откройте `frontend/amursk-city-community/`.
2. Запустите `python -m http.server 8000`.
3. Откройте `http://localhost:8000`.
4. Для публикации фронтенда загрузите содержимое этой папки в GitHub Pages.

## Как запустить API и базу локально
Следуйте `../README.md` и `DEPLOY_CLOUD_RU.md`. Важно: текущий интерфейс пока не подключён к API, поэтому регистрация и сообщения в интерфейсе не становятся общими между пользователями.

## Сущности базы
- users — учётная запись, публичная часть профиля и закрытое поле private_address.
- listings — объявления.
- conversations / conversation_members / messages — диалоги и сообщения.
- job_applications — отклики на подработку.
- reviews — отзывы после выполненного задания.

## Повседневное администрирование после production-доработки
1. Проверять очередь жалоб.
2. Скрывать мошеннические/опасные объявления и блокировать нарушителей по утверждённым правилам.
3. Не запрашивать и не публиковать лишние персональные данные.
4. Проверять успешность резервных копий и периодически тестировать восстановление.
5. Обновлять зависимости и сервер, следить за журналами и ошибками.

## Что нельзя делать
- Не отправлять `.env` в открытые чаты и репозитории.
- Не открывать PostgreSQL в интернет.
- Не публиковать адрес проживания, телефон и документы пользователя без законного основания и явного согласия.
- Не считать тестовую локальную переписку настоящими сообщениями.
