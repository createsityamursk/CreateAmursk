# АМУРСК — город рядом (City Community v3)

Обновлённый адаптивный прототип городской платформы. Сделан на чистых HTML, CSS и JavaScript без сборщика и внешних библиотек.

## Что сделано в этой версии
- Полностью обновлённая тёмная палитра: графитовый фон, холодные синие оттенки, бирюзовые градиенты, подсветка интерактивных элементов.
- Главная лента объявлений с поиском, сортировкой и фильтрами.
- Категории: «Отдам даром», «Подработка», «Продам», «Потеряно», «Найдено», «Транспорт», «Услуги».
- Подкатегории меняются в зависимости от выбранной категории.
- Создание объявления с описанием, оплатой, районом и автором.
- Просмотр карточки объявления и демонстрационный переход в сообщения.
- Локальные демонстрационные диалоги, отправка сообщений и сохранение переписки в браузере.
- Профиль с именем, статусом, районом, аватаром и обложкой; подсчёт своих объявлений.
- Раздел «Наш Амурск»: историческая хронология, галерея-концепт, истории жителей.
- Мобильная адаптация, нижняя навигация и PWA-манифест/service worker.

## Запуск
Откройте `index.html` либо запустите локальный сервер:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

## GitHub Pages и установка на Android
1. Распакуйте архив.
2. Загрузите содержимое папки `amursk-city-community` в корень репозитория GitHub.
3. В Settings → Pages включите публикацию из ветки `main`, папка `/ (root)`.
4. Откройте выданный HTTPS-адрес в Chrome на Android.
5. Выберите «Установить приложение» или «Добавить на главный экран».

## ВАЖНО: что пока является демонстрацией
Эта версия — законченный фронтенд-прототип, но не работающая общегородская соцсеть:
- Профиль и объявления сохраняются только в localStorage конкретного браузера.
- Переписка сохраняется только на этом устройстве. Другой пользователь её не получит.
- Нет подтверждения личности, регистрации Google/Mail.ru/VK ID или по SMS.
- Галерея и истории пока демонстрационные; публикации между жителями не синхронизируются.
- Фото в аватаре/обложке задаются URL, серверной загрузки файлов нет.
- Счётчик выполненных заказов пока не начисляется: для достоверного рейтинга нужен механизм подтверждения обеими сторонами.

## Что необходимо для настоящего запуска
Рекомендуемая архитектура:
- **Supabase**: PostgreSQL, Auth, Storage, Realtime и Row Level Security.
- **Вход**: Google OAuth, email magic link/password; Mail.ru — через VK ID/OAuth при доступной регистрации приложения; телефон — SMS-провайдер.
- **Сообщения**: таблицы conversations/messages + Supabase Realtime.
- **Объявления**: listings, categories, listing_photos, favorites.
- **Профили**: profiles с публичным районом, но без публичного домашнего адреса.
- **Заказы**: jobs/applications, статусы и подтверждение завершения заказчиком и исполнителем.
- **Модерация**: жалобы, блокировка пользователей, скрытие объявлений, лимиты и журнал действий.
- **Безопасность**: RLS-политики, серверная валидация, проверка типов/размеров файлов, CAPTCHA/rate limiting.

GitHub Pages подходит для статического сайта, но не заменяет сервер и базу данных. Ключи service-role и SMS-секреты нельзя помещать во фронтенд.
