# Shadow Kingdom v0.9.0

Браузерная RPG Strategy с локальными сохранениями. На этом этапе не требует собственного сервера или базы данных для игрового прогресса. Для показа рекламы AdsGram проект должен быть опубликован по HTTPS как Telegram Mini App и иметь рекламный Block ID издателя.

## Публикация обычной веб-версии
1. Распакуйте архив.
2. Загрузите содержимое `Shadow-Kingdom` в корень сайта.
3. Сохраните структуру `index.html`, `css/`, `js/`, `assets/`.
4. Откройте сайт по HTTPS. Для локального теста можно использовать `python -m http.server 8000`.

## AdsGram: обязательная настройка перед модерацией
Официальная интеграция Rewarded/Interstitial: https://docs.adsgram.ai/publisher/reward-interstitial-integration.
1. Создать Telegram-бота и настроить Mini App с HTTPS URL игры. Официальная инструкция AdsGram: https://docs.adsgram.ai/publisher/get-block-id.
2. Проверить, что Mini App открывается и полноценно работает в Telegram на мобильном устройстве и desktop.
3. Получить Rewarded Block ID в кабинете издателя AdsGram.
4. Для разработки можно создать отдельную Test platform: AdsGram указывает, что тестовая платформа может быть активна без модерации, но её показы не учитываются в статистике.
5. Для production создать Reward block, скопировать Block ID и заменить пустое значение `ads.blockId:''` в `js/config.js`.
6. Загрузить обновлённую сборку на HTTPS URL Mini App, проверить rewarded-показ внутри Telegram и отправить платформу/блок на модерацию кнопкой `Start` в кабинете.
7. В заявке явно указать размещение: экран «Королевство» → карточка «Сундук хранителя». Пользователь сам нажимает кнопку и заранее видит размер бонуса.

**Важно:** AdsGram описывает Rewarded/Interstitial интеграцию как предназначенную для Telegram Mini Apps. Наличие SDK в HTML не означает, что издательский доступ или Block ID уже выданы. Контроллер SDK кэшируется и создаётся один раз на Block ID; награда выдаётся только при `done === true` и отсутствии ошибки. Модерация не гарантируется. Сейчас награда хранится на клиенте в localStorage: для одиночной игры без backend это приемлемо как прототип, но такое начисление можно подделать через инструменты браузера. Не используйте его для денежных выплат или ценных внешних активов. Не делайте просмотр обязательным условием доступа к игровым функциям, не обещайте денежные выплаты и не выдавайте награду при ошибке/пропуске рекламы.

## Управление в бою
- Базовые атаки выполняются автоматически.
- Нажмите на героя, чтобы выбрать его; голубые ромбы показывают допустимые точки перемещения в пределах 3 шагов. Зелёные ромбы отмечают укрытия, каменные объекты блокируют движение и линию выстрела, красные клетки показывают предупреждение босса. Непроходимые клетки и занятые позиции исключены.
- Выберите способность на панели и нажмите на видимого противника; лечение выбирает наиболее раненого союзника автоматически. Если способность выбрана, доступные разрушаемые объекты подсвечиваются янтарным — по ним тоже можно целиться. Повторное нажатие выбранной способности отменяет прицеливание.
- Пауза, скорость 1×/2× и отступление доступны сверху. Призрачный рыцарь и пепельные гончие пытаются фланкировать заднюю линию; стрелки ищут позицию с открытой линией огня. Заморозка/оглушение временно отключают действия врага, замедление снижает темп его атак, метка увеличивает получаемый урон.

## Ограничения и проверки
Это развиваемый одиночный прототип, а не коммерческая MMORPG. Тактическая арена использует изометрическую проекцию логической сетки 10×6 и четырёхнаправленное перемещение, а не свободный навмеш. Укрытия и разрушаемые объекты размещены на заранее заданных клетках; высот и физики траекторий снарядов пока нет. Перемещение врага выполняется по клеткам с CSS-рывком. Анимации CSS, а не покадровые sprite sheets. Звук остаётся UI-заглушкой. Сохранения хранятся в конкретном браузере и не синхронизируются между устройствами. Rewarded-реклама требует Telegram Mini App, реального Block ID и отдельной проверки в аккаунте AdsGram. Полный браузерный запуск этой версии в среде сборки не подтвердился из-за тайм-аута Chromium; для ручной проверки открой проект через локальный HTTP-сервер или HTTPS-хостинг.

Проверяйте запуск через локальный HTTP-сервер или на HTTPS-хостинге; открытие через `file://` может ограничивать браузерные функции. Chromium headless в среде текущей сборки завершился по тайм-ауту, поэтому реальный браузерный smoke-test здесь не был подтверждён; выполнены статические проверки и запуск логики в Node с DOM-заглушками. В сборке выполняется проверка синтаксиса JS, структуры HTML и целостности ZIP. Реальный рекламный показ не может быть проверен без выданного Block ID и Telegram Mini App.

## Экипировка v0.6.0
Победы в обычных вылазках имеют настраиваемый шанс выпадения предмета (`progression.gearDropChance` в `js/config.js`). Победа над боссом гарантирует эпическую экипировку. Предметы занимают слот оружия, брони или реликвии; на одного героя можно надеть не более одного предмета каждого слота. В инвентаре можно назначать, заменять и снимать экипировку. Бонусы к характеристикам записываются в локальное сохранение.

## Тактика v0.9.0
Арена использует изометрическую проекцию сетки 10×6. При выборе героя голубые ромбы показывают достижимые позиции в пределах 3 шагов. Каменные стены блокируют движение и линию видимости; дальние автоатаки и направленные способности не проходят сквозь них. Зелёные клетки укрытия уменьшают дальний урон на 35%. Часть стен и укрытий имеет прочность: автоатаки или направленная способность могут разрушить объект; после этого клетка становится проходимой и перестаёт блокировать линию выстрела. При выборе способности разрушаемые объекты в радиусе подсвечиваются. Некромант размечает красную область проклятого удара. Фланкеры стремятся зайти к уязвимым героям с края строя, стрелки ищут позицию с линией огня. Контрольные эффекты: оглушение, заморозка, замедление и метка уязвимости.
